# Issue #1 — Build a semantic bio page (header, main, footer)

**Tier:** Beginner (1pt)

## What to build

Create a single-page personal bio using semantic HTML elements. Use `<header>` for your name and introduction, `<main>` for your main content, and `<footer>` for a closing note.

The page should describe who you are and provide a simple introduction to your background or interests.

## Requirements

- Use `<header>` for your name and introduction
- Use `<main>` for the primary page content
- Use `<footer>` for a closing note
- Do not use any `<div>` elements
- Use appropriate semantic HTML elements throughout the page

## Where to put your work

```
challenges/block-1/01-semantic-bio-page/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Uses semantic HTML with no unnecessary `<div>` elements
- PR opened against `main`, linked to this issue (`Addresses #1`)

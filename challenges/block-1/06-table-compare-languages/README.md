# Issue #6 — Build a simple table comparing 3 programming languages

**Tier:** Beginner (1pt)

## What to build

Use `<table>`, `<thead>`, and `<tbody>` to compare 3 languages (e.g. HTML, CSS, JS) across at least 2 criteria, such as difficulty and typical use case.

## Requirements

- Use `<table>`, `<thead>`, and `<tbody>`
- Compare exactly 3 programming languages
- At least 2 comparison criteria (columns), e.g. difficulty, typical use case
- Use `<th>` for header cells

## Where to put your work

```
challenges/block-1/06-table-compare-languages/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Table uses `<thead>`/`<tbody>` correctly with `<th>` header cells
- PR opened against `main`, linked to this issue (`Addresses #6`)

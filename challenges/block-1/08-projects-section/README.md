# Issue #8 — Structure a 'Projects' section using `<section>`

**Tier:** Beginner (1pt)

## What to build

Create a `<section id="projects">` with a heading and at least 2 project entries, each briefly described in plain text.

## Requirements

- Use `<section id="projects">`
- Include a heading (e.g. `<h2>Projects</h2>`)
- At least 2 project entries, each with a short plain-text description

## Where to put your work

```
challenges/block-1/08-projects-section/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- `<section id="projects">` contains a heading and 2+ described projects
- PR opened against `main`, linked to this issue (`Addresses #8`)

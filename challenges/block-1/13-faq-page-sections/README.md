# Issue #13 — Build a FAQ page using `<section>` per question, no CSS

**Tier:** Intermediate (3pt)

## What to build

Create at least 5 question/answer pairs, each in its own `<section>`, with the question as a heading and the answer as a paragraph.

## Requirements

- At least 5 `<section>` elements, one per question
- Each section has a heading (the question) and a `<p>` (the answer)
- No CSS applied

## Where to put your work

```
challenges/block-1/13-faq-page-sections/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- 5+ Q&A sections, each with a heading and paragraph answer
- PR opened against `main`, linked to this issue (`Addresses #13`)

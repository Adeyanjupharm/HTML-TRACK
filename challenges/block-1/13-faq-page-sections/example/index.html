Frequently Asked Questions

What is the Hey_Techys mentorship track?

It's a monthly program where participants complete small, scored coding challenges to build real skills.

Do I need to know CSS to start Block 1?

No. Block 1 is entirely focused on semantic HTML — no CSS is used at all.

How are points awarded?

Points are only awarded once your pull request is reviewed and merged into main.

Can I work ahead into Block 2?

Block 2 issues open at the start of week 3, so it's best to focus on Block 1 first.

What happens if my PR needs changes?

A maintainer will leave feedback, and you push new commits to the same branch until it's approved.

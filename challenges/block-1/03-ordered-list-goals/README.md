# Issue #3 — Create an ordered list of your top 3 learning goals

**Tier:** Beginner (1pt)

## What to build

Use `<ol>` to list your top 3 learning goals for this program, in priority order. Each item should be a full sentence, not just a keyword.

## Requirements

- Use `<ol>` for the list
- Exactly 3 `<li>` items
- Each item is a full sentence, not just a keyword or phrase
- Items are ordered by priority (most important first)

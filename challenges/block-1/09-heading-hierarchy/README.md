# Issue #9 — Add heading hierarchy (h1-h3) to an existing page without skipping levels

**Tier:** Beginner (1pt)

## What to build

Take an existing page (yours or a provided starter) and correct its heading structure so `h1` → `h2` → `h3` flows logically with no skipped levels.

## Requirements

- Exactly one `<h1>` per page
- No heading level is skipped (e.g. no jump straight from `<h1>` to `<h3>`)
- Headings reflect the actual content hierarchy of the page

## Where to put your work

```
challenges/block-1/09-heading-hierarchy/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Heading levels flow h1 → h2 → h3 with none skipped
- PR opened against `main`, linked to this issue (`Addresses #9`)

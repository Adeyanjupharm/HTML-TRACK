# Issue #7 — Add a footer with copyright text and a link

**Tier:** Beginner (1pt)

## What to build

Build a `<footer>` containing a copyright line and at least one working link, such as back to your GitHub profile.

## Requirements

- Use `<footer>`
- Include a copyright line (e.g. `&copy; 2026 Your Name`)
- At least one working `<a>` link (e.g. to your GitHub profile)

## Where to put your work

```
challenges/block-1/07-footer-copyright-link/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- `<footer>` includes a copyright line and a working link
- PR opened against `main`, linked to this issue (`Addresses #7`)

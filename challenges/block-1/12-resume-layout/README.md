# Issue #12 — Recreate a simple resume layout using only semantic HTML

**Tier:** Intermediate (3pt)

## What to build

Structure a one-page resume (experience, education, skills) using semantic sectioning elements — no CSS, no visual styling, structure only.

## Requirements

- Use semantic sectioning elements (`<header>`, `<main>`, `<section>`, `<footer>`)
- Include sections for Experience, Education, and Skills at minimum
- No `<div>` elements and no inline styling

## Where to put your work

```
challenges/block-1/12-resume-layout/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Fully structured with semantic elements only, no `<div>` or styling
- PR opened against `main`, linked to this issue (`Addresses #12`)

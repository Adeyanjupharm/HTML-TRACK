# Issue #4 — Create an unordered list of your tech stack interests

**Tier:** Beginner (1pt)

## What to build

Use `<ul>` to list the technologies or areas you're most interested in learning. Minimum 4 items.

## Requirements

- Use `<ul>` for the list
- At least 4 `<li>` items
- Each item names a specific technology or area (not a vague category)

## Where to put your work

```
challenges/block-1/04-unordered-list-tech-stack/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Uses `<ul>` with at least 4 specific items
- PR opened against `main`, linked to this issue (`Addresses #4`)

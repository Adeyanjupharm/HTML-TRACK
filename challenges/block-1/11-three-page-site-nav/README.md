# Issue #11 — Build a 3-page site (index, about, contact) linked via `<nav>`

**Tier:** Intermediate (3pt)

## What to build

Create `index.html`, `about.html`, and `contact.html` as separate files, each containing a shared `<nav>` that links to all three pages.

## Requirements

- Three separate HTML files: `index.html`, `about.html`, `contact.html`
- Each page includes an identical `<nav>` linking to all 3 pages
- Each page has unique `<main>` content relevant to its purpose
- Do not use any `<div>` elements

## Where to put your work

```
challenges/block-1/11-three-page-site-nav/(your-name)/index.html
challenges/block-1/11-three-page-site-nav/(your-name)/about.html
challenges/block-1/11-three-page-site-nav/(your-name)/contact.html
```

## Definition of done

- All three pages build and display correctly in a browser
- Nav links correctly move between all three pages
- PR opened against `main`, linked to this issue (`Addresses #11`)

# Issue #5 — Add a profile image with descriptive alt text

**Tier:** Beginner (1pt)

## What to build

Add an `<img>` element with a real photo or placeholder, and write alt text that actually describes the image content — not "image" or "photo".

## Requirements

- Use `<img>` with a valid `src`
- `alt` attribute describes the image content specifically (not "image", "photo", or left empty)
- Image displays correctly when the page is opened in a browser

## Where to put your work

```
challenges/block-1/05-profile-image-alt-text/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- `<img>` has a specific, descriptive `alt` attribute
- PR opened against `main`, linked to this issue (`Addresses #5`)

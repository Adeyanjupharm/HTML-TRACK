# Issue #15 — Build a full semantic landing page skeleton (header, main w/ 3 sections, footer) with zero `<div>` tags

**Tier:** Advanced (6pt)

## What to build

The capstone Block 1 challenge: build a full landing page skeleton using only semantic elements throughout — no `<div>` anywhere — and validate it passes the W3C HTML validator with zero errors.

## Requirements

- `<header>`, a `<main>` containing exactly 3 `<section>` elements, and a `<footer>`
- Zero `<div>` elements anywhere in the document
- Passes the [W3C Markup Validator](https://validator.w3.org/) with zero errors

## Where to put your work

```
challenges/block-1/15-landing-page-skeleton/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Zero `<div>` elements; passes the W3C validator with zero errors
- PR opened against `main`, linked to this issue (`Addresses #15`)

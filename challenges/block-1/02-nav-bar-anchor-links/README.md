# Issue #2 — Add a nav bar with 3 anchor links using `<nav>`

**Tier:** Beginner (1pt)

## What to build

Build a `<nav>` containing 3 anchor links that jump to sections on the same page using `#id` anchors. Each link needs clear, descriptive text — not "click here".

## Requirements

- Use `<nav>` to wrap the links
- Include exactly 3 `<a>` links
- Each link must use a fragment identifier (`#id`) pointing to a section on the same page
- Link text must be descriptive of its destination (not "click here" or "link")
- Do not use any `<div>` elements

## Where to put your work

```
challenges/block-1/02-nav-bar-anchor-links/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- All 3 links scroll to their matching section when clicked
- PR opened against `main`, linked to this issue (`Addresses #2`)

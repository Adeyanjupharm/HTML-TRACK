# Issue #10 — Wrap a blog-style write-up in `<article>`

**Tier:** Intermediate (3pt)

## What to build

Write a short (150+ word) post about something you learned this week, wrapped in `<article>` with its own heading.

## Requirements

- Use `<article>` to wrap the entire post
- Include a heading inside the `<article>`
- Body text is at least 150 words

## Where to put your work

```
challenges/block-1/10-article-blog-writeup/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- `<article>` contains a heading and 150+ words of body text
- PR opened against `main`, linked to this issue (`Addresses #10`)

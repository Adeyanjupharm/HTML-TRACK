# Hey_Techys — September Project: Profile & Contact Hub

Welcome! This is the shared project repo for the Hey_Techys mentorship program's September track — **HTML Fundamentals (Block 1)** and **Forms, Accessibility & SEO (Block 2)**.

No CSS this month. The goal is pure structure: semantic HTML, and functional, accessible forms.

## How this repo works

- `main` is the shared branch. It only ever contains **finished, merged work**.
- Every open issue on GitHub corresponds to one small build task.
- You pick an unclaimed issue, build it on your own branch, and open a PR back into `main`.
- Once your PR is reviewed and merged, you get the points for that issue.

See `CONTRIBUTING.md` for the exact step-by-step workflow — read it before your first PR.

## Structure

```
hey-techys-september/
├── README.md
├── CONTRIBUTING.md
├── index.html                  ← hub page, links out to every challenge
└── challenges/
    ├── block-1/                ← HTML Fundamentals challenges
    │   └── (your challenge folders go here)
    └── block-2/                ← Forms, Accessibility & SEO challenges
        └── (your challenge folders go here)
```

Each challenge you build gets its **own folder** inside `challenges/block-1/` or `challenges/block-2/`, named after the issue. This keeps everyone's work isolated — your PR won't conflict with anyone else's, no matter how many people are building at the same time.

## Scoring

Beginner = 1 point · Intermediate = 3 points · Advanced = 6 points. Points are only counted once your PR is merged into `main`. Full rules are in the pinned Slack post and the scoring spreadsheet.

## Getting started

```bash
git clone https://github.com/hey-techys/september-project.git
cd september-project
git checkout -b issue-03-ordered-list-goals
```

Then follow `CONTRIBUTING.md`.
